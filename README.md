# Nose-Driven Bird Game

🐦 Fun little interactive game made using MediaPipe Pose Landmarker.

## Installation

### 1. Clone the repository.
```bash
git clone [https://github.com/Gamushiro/pose-driven-game](https://github.com/Gamushiro/pose-driven-game)
```
### 2. Navigate into the directory.
```bash
cd pose-driven-game
```
### 3. Install dependencies.
```bash
pip install -r requirements.txt
```
### 4. Install the pose landmarker.
Installation link: https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task

### 5. Type into terminal.
```bash
streamlit run app.py
```
### 6. Enjoy
